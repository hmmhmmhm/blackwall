Explicit assumptions of the current functional profile:
- The model provides service 2/4 control completion based on configuration, trigger, and virtual time; it does not execute sensor ROM calculations.
- Cold gyro accuracy is declared as 0. The accuracy result is supplied as 4 bytes at 0x5bc.
- Clock correction is nominally 1×, providing the host-requested gyro PDR at 0x294 as DT at 0x4a0 for consumption. The mathematics of actual trim is unverified.
- The subsequent GAF mode 0x1be write is an actual host SRAM write observed in the original and checked against the SDK name.
- The screen backend reuses the existing L8 ring consumer/area-reference GPU model. This is not a determination of agreement with physical MSAA or an optical panel.
