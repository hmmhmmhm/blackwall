# Fixed-point quad and coverage reference profile

bw346 resumption design. Execution of 16 combinations of original AA function confirmed edges 0/1/2/3 correspond to bits 26/25/24/23 respectively. Thus DRAW_CMD `0x02800005` is quad 5 with edge 1/3 AA. Do not apply MATMULT register's MMUL_QUAD_BEZ constant to this DRAW_CMD. Original quad emitter's 18 words also matched the first quad segment of actual 252 words. This evidences CPU command generation, not physical GPU MSAA sample positions, quantization, or rounding.

Choices are manufacturer bit-exact raster implementation, explicit mathematical reference coverage, or continued rejection. Manufacturer implementation and exact sample pattern were not obtained. Without replacing original geometry with lines/rectangles, **retain default rejection and use an opt-in area reference profile**. This functional model handles arbitrary verified convex 16.16 quads, per-edge AA, clip, and L8 compositing; it is not a bypass accepting only expected screens or particular coordinates.

AA edges use intersection area between unit pixel and half-plane. Non-AA edges use pixel center and consistent half-open boundary rules. Area coverage is effective alpha in SIMPLE blend with 8-bit half-up rounding. These are explicit reference rules, not bit identity with hardware MSAA. No DMA/state/completion is applied before convexity/winding, coordinates, shader, color, memory, and workload validation. Inverted clip generated by offscreen path is treated as empty.

First test fractional squares with mathematically known areas, direction/clip, invalid polygons, strict default rejection, and original 252-word black/white variants. Then check original M55 execution under the same profile and guest surface/IRQ/failure boundaries. Record profile name and unknowns in capture; reference execution success is not promoted to natural main, physical GPU, or overall goal completion.
