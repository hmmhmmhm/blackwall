# G2 board flow prototype

2026-11-18 · bw-0587. The [standalone HTML](../../web/prototypes/board-explorer.html) is a layout prototype opened in a local browser. It is not connected to an actual device or emulator events.

Eight frames at six-second intervals were examined from 20:32–21:20 of [Even Realities G2 - Almost Perfect HUD](https://www.youtube.com/watch?v=4C5AhvTf2fI). A detached temple end and elongated board are visible around 20:44–20:56; metal covers, square components, and gold contacts on a board with its connector disconnected appear around 20:56–21:14. Times are approximate positions within the extracted segment. The form resembles the user's first photo, but this is not evidence of the same device, board side, or left/right orientation. Markings and circuit connections cannot be read from these samples, so chip models and their precise roles and locations remain unconfirmed.

The video-frame contact sheet is retained outside Git at `research/board-video-bw587/contact.jpg` solely for source review. The extracted video segment was removed after review and was not included in the HTML. Redistribution rights require separate confirmation.

The HTML places a virtual board, detail panel, four-stage flow, and evidence-status legend. Buttons change both the description and selected stage. Positions, connecting lines, and ordering are conceptual, not measurements or a communication trace. In a dedicated minimized Safari window, loading, eight buttons, and detail/stage text changes after graphic clicks were checked through the DOM. The task window and server were closed. Responsive CSS exists, but actual mobile layout and visual captures were not reviewed. The HTML includes no photos or third-party video.
