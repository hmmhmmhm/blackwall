# Stock 2.4 virtual hardware model

These four components are the frozen model used by the stock 2.4 original-boot profile. Their SHA-256 hashes are recorded in [the profile](../../docs/data/original-boot-stock24-profile.json). The model is experimental and does not establish physical hardware behavior.

`strict.cs` includes Renode-derived code with its original copyright and MIT license notices. See [third-party notices](../../NOTICE.md) and [the Renode license](../../licenses/renode.txt). Firmware images are not included.
